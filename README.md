# Tuk-Tuk Vehicle Page (clone)

Static Arabic RTL page. No build step.

## Run
- Open `index.html` in a browser, or
- In VS Code install the **Live Server** extension, right-click `index.html` -> *Open with Live Server*.

## Structure
- `index.html`   page skeleton
- `css/style.css` styles (light/dark theme variables at the top)
- `js/data.js`   sample vehicles (edit here)
- `js/app.js`    rendering logic

Switch vehicle with `index.html#1`, `index.html#2`.
